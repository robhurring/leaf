# GitHub flavored markdown

Everything GitHub renders in a `.md` file, in one place.

## Tables

| Left   |  Center  | Right |
| :----- | :------: | ----: |
| a      |    b     |     c |
| `code` | **bold** |  _em_ |

## Task lists

- [x] Done thing
- [ ] Open thing
  - [ ] Nested open thing

## Strikethrough and footnotes

~~Removed~~ text with a footnote.[^1]

[^1]: The footnote body.

## Autolinks

Visit https://example.com or email a@b.com.

## Nested lists

1. First
   - inner bullet
   - another
2. Second
   1. deep ordered

## Blockquote with a heading inside

> ### Quoted heading
>
> Quoted paragraph with **emphasis**.

## Emoji

Shortcodes like :tada: render as emoji.
